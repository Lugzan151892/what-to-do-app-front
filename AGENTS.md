# AGENTS.md — what-to-do-app-front («Weeknd»)

Фронтенд приложения, которое помогает находить идеи, чем заняться в выходные. Пользователь ведёт историю активностей и ставит им оценки, а по запросу получает AI-идеи. Перед генерацией он задаёт настройки: сколько человек, только новое, бюджет, город. AI подбирает актуальные события в городе на текущую дату. Подробнее — [product.md](docs/agents/product.md).

Сейчас готовы на моках: лендинг, UI входа и регистрации (`/login`, `/registration`, без логики) и флоу AI-генерации (`/generation` → `/generation/result` → `/generation/<id>`, доступен без авторизации). Бэкенда, API, авторизации, стейт-менеджмента и тестов пока нет.

## Как пользоваться документацией
- Этот файл действует для всего репозитория и служит единой точкой входа для coding-агентов.
- Перед архитектурными изменениями прочитать `product.md` и `architecture.md`.
- Остальные документы читать по задаче: правила кода, стили, компоненты или известные проблемы.
- Если изменение делает документацию неточной, обновить соответствующий файл в `docs/agents/` в той же задаче.
- Не исправлять известный техдолг попутно, если он не относится к запросу пользователя.

## Стек
- Next.js 16 (App Router) + React 19 + TypeScript (strict)
- Стили: SCSS/CSS Modules + собственные глобальные утилитарные классы с префиксом `w-` (Tailwind **не подключён**)
- ESLint 9 (flat config) + `@stylistic`
- Тексты интерфейса — на русском

## Команды
- `npm run dev` — dev-сервер (http://localhost:3000)
- `npm run build` — прод-сборка (заодно проверка типов)
- `npm run lint` — ESLint (запускать после изменений)

## Ключевые правила (кратко)
1. Импорты — только абсолютные через алиас `@/` (= `src/`), полный путь до файла. Относительные пути (`./`, `../`) не использовать, даже для соседних файлов.
2. Один компонент = одна папка в kebab-case: `Component.tsx` + `component.module.scss`.
3. Компоненты — стрелочные функции `const X: React.FC<IXProps> = (...) => {}` + `export default X;`.
4. Интерфейсы — `I` префикс, типы — `T`, enum — `E` + UPPER_SNAKE (`EBUTTON_TYPE`).
5. Классы собираем через `clsx` из `@/app/utils/style-utils/clsx` (свой, не npm).
6. Раскладка/отступы/типографика — глобальные `w-*` классы; уникальная визуалка — в CSS-модуле компонента.
7. Цвета — только CSS-переменные из `src/styles/colors.css` (`var(--accent)` и т.д.).
8. Код-стиль: одинарные кавычки, 2 пробела, `;` обязательна, в JSX при >1 пропе — каждый пропс на своей строке.
