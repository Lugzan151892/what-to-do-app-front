# what-to-do-app-front («Weeknd»)

Фронтенд приложения, которое помогает находить идеи, чем заняться в выходные. Пользователь ведёт историю активностей и ставит им оценки, а по запросу получает AI-идеи. Перед генерацией он задаёт настройки: сколько человек, только новое, бюджет, город. AI подбирает актуальные события в городе на текущую дату. Подробнее — [product.md](.claude/docs/product.md).

Сейчас готова только вёрстка лендинга с моками. Экранов приложения, авторизации, бэкенда, API, стейт-менеджмента и тестов пока нет.

## Стек
- Next.js 16 (App Router) + React 19 + TypeScript (strict)
- Стили: SCSS/CSS Modules + собственные глобальные утилитарные классы с префиксом `w-` (Tailwind **не подключён**)
- ESLint 9 (flat config) + `@stylistic`
- Тексты интерфейса — на русском

## Команды
- `npm run dev` — dev-сервер (http://localhost:3000)
- `npm run build` — прод-сборка (заодно проверка типов)
- `npm run lint` — ESLint (запускать после изменений)

## Ключевые правила (кратко)
1. Импорты — через алиас `@/` (= `src/`), полный путь до файла.
2. Один компонент = одна папка в kebab-case: `Component.tsx` + `component.module.scss`.
3. Компоненты — стрелочные функции `const X: React.FC<IXProps> = (...) => {}` + `export default X;`.
4. Интерфейсы — `I` префикс, типы — `T`, enum — `E` + UPPER_SNAKE (`EBUTTON_TYPE`).
5. Классы собираем через `clsx` из `@/app/utils/style-utils/clsx` (свой, не npm).
6. Раскладка/отступы/типографика — глобальные `w-*` классы; уникальная визуалка — в CSS-модуле компонента.
7. Цвета — только CSS-переменные из `src/styles/colors.css` (`var(--accent)` и т.д.).
8. Код-стиль: одинарные кавычки, 2 пробела, `;` обязательна, в JSX при >1 пропе — каждый пропс на своей строке.
